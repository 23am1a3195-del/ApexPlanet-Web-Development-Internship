
# ApexPlanet Internship - Task 2

## Project Title
My Productivity Hub

## Description
This project is developed as part of my ApexPlanet Web Development Internship.

My Productivity Hub is a simple web application that helps users organize their daily activities and manage tasks.

## Technologies Used
- HTML
- CSS
- JavaScript
- Visual Studio Code

## Features
1. Contact Form
2. Name, Email and Message fields
3. Form validation
4. Success and error messages
5. Add new tasks
6. Mark tasks as completed
7. Delete tasks

## Project Structure

ApexPlanet_Task2/
- index.html
- style.css
- script.js
- README.md

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Use the contact form and To-Do List.
